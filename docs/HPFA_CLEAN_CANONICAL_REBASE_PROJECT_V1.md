## Source Authority Model

### Termux modern execution source

```text
/data/data/com.termux/files/home/hpfa_claim_integrity/hpfa
```

Primary execution lab. This source contains the most modern runtime traces, ACTIVE_MATCH work, and actual generated artefacts.

### HPFA integrity single tree

The active project tree. It is reviewed first. Every useful kernel inside it must be classified, grouped by capability, and either bound, merged into a composite, quarantined, or demoted.

### Termux HOME

Second-phase salvage zone. It is reviewed only after the HPFA integrity single tree has been exhausted.

### GitHub

Canonical code authority candidate. GitHub is not assumed to be the modern source. Code becomes production-ready only after ACTIVE_MATCH execution evidence exists in Termux.

### Dropbox

Package, donor, archive, direct-use pack, coordinator pack, and handoff source. Dropbox is not runtime authority.

### Google Drive

Constitution, documentation, registry, claim boundary, and publication-standard authority. Google Drive documents are not runtime artefacts until converted into code contracts, registries, or policy rules.

### ACTIVE_RUNTIME

```text
runtime/active_single_match/current
```

The only active match runtime authority.
