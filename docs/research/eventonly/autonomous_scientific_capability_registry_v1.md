# HPFA Autonomous Scientific Capability Registry V1

Status: `RESEARCH_HARDENED_CAPABILITY_MAP / NOT_PRODUCTION`

Purpose: preserve every advanced scientific/analytical capability proposed for HPFA, classify it against current event-only evidence authority, and prevent attractive mathematics from exceeding the observation model. Donor/Drive/Dropbox/academic sources are `REFERENCE_ONLY / DONOR_SUPPORT`; ACTIVE_MATCH remains the only runtime match truth.

## Admission states

- `IMPLEMENTED_CANDIDATE_ONLY`: executable now, bounded to visible/admitted evidence.
- `NEXT_FOUNDATION_NODE`: high-value next product node after current upstream gate.
- `DEFERRED_PREREQUISITE`: scientifically plausible but requires an upstream contract/data regime not yet admitted.
- `VISUALIZATION_ONLY_SYNTHETIC`: may interpolate/visualize observed anchors but cannot be promoted to physical truth.
- `RESEARCH_ONLY`: useful conceptual research; not yet a product metric/claim.
- `REJECT_AS_TRUTH`: current event-only data cannot identify the claimed latent physical/mental/tactical state.

## Global invariants

```text
surface row != canonical event
CSV/XML reflection != independent evidence
XLSX aggregate != event ground truth
interpolation != tracking truth
predictive dependence != causal mechanism
mathematical sophistication != evidence admission
```

Runtime must also follow `docs/contracts/self_contained_runtime_dependency_policy_v1.md`: no required network, cloud inference, runtime model download or donor import.

## 1. Spatial distribution and information theory

### Grid occupancy / Shannon entropy / HHI / effective-cell count
State: `IMPLEMENTED_CANDIDATE_ONLY` in Statistical Spatial Evidence Lite V1.

Safe output: eligible row-nucleus coordinate evidence is more concentrated/distributed across a declared grid.

Forbidden promotion: tactical unpredictability, creativity, dominance, team shape, pitch control.

### Surprisal / information shock
State: `DEFERRED_PREREQUISITE`.

Required: admitted observation unit + context-conditioned baseline probability `P(e|state)` + calibration population + reflection-safe denominator.

Safe future output: `SURPRISAL_CANDIDATE = -log2 P(observed_label | admitted_context)`.

Forbidden: surprising event = tactical error/causal breakdown.

### Information Bottleneck
State: `DEFERRED_PREREQUISITE`.

Required: stable admitted representation X, explicit target Y, independent training/evaluation units and validation showing compression retains predictive information. The assertion that a fixed percentage of events is “tactical noise” is not admissible by fiat.

## 9. Statistical inference / uncertainty

### Mann-Whitney / chi-square / rate tests
State: `DEFERRED_PREREQUISITE`.

Need independent/clustered observation-unit contract, exposure denominator, multiplicity policy and effect sizes. `p < alpha` never becomes tactical causality.

### Conformal prediction
State: `DEFERRED_PREREQUISITE`.

Required: explicit prediction target, nonconformity score, calibration population, exchangeability unit, held-out calibration and subgroup/domain-shift audit.

Invariants:
`CONFORMAL_COVERAGE != POSTERIOR_PROBABILITY`
`MARGINAL_COVERAGE != CONDITIONAL_COVERAGE`
`MANY_EVENT_ROWS != MANY_EXCHANGEABLE_UNITS`
`DISTRIBUTION_FREE != ASSUMPTION_FREE`.

### Beta-Binomial / Empirical-Bayes shrinkage
State: `DEFERRED_PREREQUISITE`.

Prior population and denominator must be validated. `n` must be eligible independent opportunities/sequences, not raw rows.

### Bivariate Poisson / Dixon-Coles / Monte Carlo score simulation
State: `DEFERRED_PREREQUISITE`.

Needs multi-match attack/defence-strength estimation, low-score/home-away policy, validated input construct and calibration. Single-match xG totals may at most support a clearly labelled descriptive reference simulation, not a fitted Dixon-Coles model or deserved-result truth.

State: `DEFERRED_PREREQUISITE / RESEARCH_ONLY`.

### Off-policy evaluation / action regret
State: `DEFERRED_PREREQUISITE`.

Requires logged behavior policy or propensity support, explicit alternative action set, learned Q/value with validation, positivity/common-support audit and uncertainty.

### Structural causal models / do-calculus
State: `DEFERRED_PREREQUISITE`.

Requires declared causal graph, intervention semantics, identifiability assumptions and sensitivity analysis. Observational labels alone do not identify causal responsibility.

### Shapley attribution
State: `DEFERRED_PREREQUISITE`.

Shapley can decompose an admitted predictive model output; it does not automatically decompose true causal blame. Safe future label: `MODEL_ATTRIBUTION_CANDIDATE`.

### Counterfactual / “shadow match” simulator
State: `DEFERRED_PREREQUISITE`.

Future output must disclose model class, interventions, uncertainty and unsupported variables. It is a model-based counter-scenario, never an alternative-match fact.

## 20. Autonomous question / abductive reasoning engine

State: `DEFERRED_PREREQUISITE`, strategic downstream target.

Architecture:

```text
admitted evidence
-> anomaly / surprise / consequence candidate
-> evidence packet
-> competing explanations
-> counter-evidence search
-> falsifier
-> analyst-facing question
```

Allowed question form:
- “Which observed upstream actions/relations are most consistently associated with this consequence candidate?”
- “What evidence contradicts the leading explanation?”
- “What observable condition would falsify this interpretation?”

Forbidden automatic answer:
- coach intention;
- hidden pressing trap;
- off-ball support isolation truth;
- cognitive fatigue;
- causal blame without identification.

Abduction proposes explanations; it does not prove them.

## 21. Coach brief / canonical post-match report adaptation

Target narrative cycle:

```text
FACT
-> FRAME
-> FINDING
-> FAULTLINE
-> FIX
-> FOLLOW-UP
```

### FACT
Only admitted match-surface/metric evidence. Use `surface rows`, `visible/action-family evidence`, not canonical-event counts.

### FRAME
Context, spatial distribution, rhythm and game-state candidates with claim ceilings visible.

### FINDING
Evidence-weighted analyst interpretation. Predictive model output is not causal truth.

### FAULTLINE
Turning-point / breakdown candidate + upstream relation evidence + counter-evidence. PELT/Hawkes/graph/value outputs remain model-relative candidates.

### FIX
At most three evidence-linked training hypotheses/recommendations. They are analyst/coach decision support, not autonomous coaching truth.

### FOLLOW-UP
Mandatory falsifier, counter-scenario and next validation condition.

Three analytical layers remain useful:
- Micro: action/decision evidence;
- Mezzo: admitted episode/sequence/relation evidence;
- Macro: match-level aggregate/context evidence.

Do not use `dominance`, `fatigue`, `pitch control`, `true compactness`, `coach plan` or causal Shapley language unless their own contracts are later admitted.
