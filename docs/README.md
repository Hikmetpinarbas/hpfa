# HPFA Documentation

This directory contains current product contracts, governance and supporting reference material.

## Authority order

1. Live GitHub product state for code/contracts/tests.
2. `docs/governance/HPFA_CURRENT_AUTHORITY_REGISTRY_V1.json` for authority resolution rules.
3. `docs/governance/HPFA_MASTER_PROJECT_DIRECTIVE_SHORT_CURRENT.md` for current product doctrine.
4. `docs/contracts/` for admitted product-node contracts.
5. Other governance/support material only within its stated scope.

Historical sprint notes, chat prompts, handoff texts, generated runtime reports and one-match acceptance artefacts are intentionally not kept in the current product tree. Git history preserves their lineage when needed.

## Structure

- `contracts/` — product-node contracts and claim boundaries.
- `governance/` — current authority, maintenance, donor and release governance.
- `audits/` — reusable product-level audits.
- `research_support/` — research support indexes/matrices.
- `brand/` — product identity material.

Documentation must not create football truth. Where documentation and executable current product behaviour disagree, the discrepancy is REVIEW_REQUIRED and must be reconciled against the current producer and runtime evidence.
