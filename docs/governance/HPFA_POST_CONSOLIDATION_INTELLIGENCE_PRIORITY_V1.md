## P0 — First class-jump football intelligence

### 3. Review / Uncertainty Propagation

Priority reason: ambiguity already exists upstream. It must survive into context, episodes, patterns and analyst output instead of being silently lost.

Target behaviours:

- preserve `REVIEW_REQUIRED`, ambiguity and indeterminate state downstream;
- distinguish missing evidence from evidence of absence;
- preserve same-time uncertainty;
- preserve source-role/identity/taxonomy/sequence review reasons;
- expose confidence/claim ceiling without manufacturing truth.

Default implementation decision: strengthen current contracts and adapters; do not open a parallel uncertainty engine unless current producers cannot carry the state.

### 4. Context Evidence Re-binding

Priority reason: sequence evidence without match-local context cannot support reliable recurrence or analyst retrieval.

Target candidate contexts:

- period/half;
- visible time window;
- restart-conditioned context;
- score-state candidate where source support is admitted;
- breakdown/recovery context;
- terminal-outcome support context;
- sequence/trace context;
- missing/unknown explicit states.

Historical Match Context Slicer apparatus is donor support only. Adapt current-safe behaviours; do not copy stale assumptions.

### 5. Analyst Episode Locator

Priority reason: this is the first direct analyst workflow multiplier. It should answer where a behaviour happened in the match without claiming possession or tactical truth.

Target queries include:

- locate visible episodes after a restart;
- locate breakdown/recovery windows;
- locate repeated behaviour under the same score/period context;
- locate trace/sequence candidates satisfying explicit evidence predicates;
- return evidence references and review state for analyst inspection.

Episode candidates are retrieval objects, not canonical events, possessions or tactical episodes.
